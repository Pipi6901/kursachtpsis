## 2. Что выполнено частично или не выполнялось

1. **Версии существующей системы (п. 3.2.4).** Angular 14 → актуальная ветка января 2026 года (21.x) и Spring Boot 3.3.5 → 3.5.x или 4.0 — многоступенчатое
   обновление (Angular — по одной мажорной версии с миграцией кода, Spring Boot — смена пакетов и конфигурации безопасности) затрагивает весь исходный
   проект, а не только новый модуль, поэтому без отдельного решения не выполнялось. Модуль написан так, чтобы его код переносился на новые версии без изменений
   логики (отдельный модуль Angular, отдельный пакет сервера).
2. **Шифрование на уровне СУБД и канала «браузер — сервер».** PostgreSQL штатно не шифрует файлы данных — для этого используется шифрование диска
   (BitLocker) либо расширения; в учебной конфигурации клиент работает с сервером по HTTP. Для эксплуатации нужен обратный прокси с HTTPS
   ([installation-windows.md](installation-windows.md#8-https-между-узлами)). Шифруются модели, резервные копии и канал между сервером и интеллектуальным сервисом.
3. **Реальные данные.** В проекте нет реальных продаж и затрат; модуль заполнен синтетическими данными (так как продажи гостиницы в исходной системе —
   это бронирования номеров, а не ряд по неделям с маркетинговыми затратами). Данные вносятся вручную или загружаются из CSV. Интеграция с бронированиями
   исходной системы (ряд продаж как агрегат по реальным бронированиям) не выполнялась, чтобы не затрагивать существующие данные.
4. **Размещение на нескольких физических узлах** проверено конфигурацией и поведением при недоступности/смене адреса, но не на нескольких компьютерах.
5. **Пояснительная записка, плакаты, диаграммы BPMN/UML** (разделы 4–6 задания) не входили в программную реализацию. Материалы для них подготовлены (раздел 3).

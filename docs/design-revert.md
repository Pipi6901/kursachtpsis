# Новый дизайн сайта и возврат к прежнему

Дизайн сайта обновлён (версия 2): единая система кнопок и полей, ровная сетка номеров, галерея фотографий, значки
удобств, новые шапка, подвал и главная страница. **Палитра прежняя** (акцент `#dfa974`, тёмно-синий `#222736`,
серые и белый), добавлены только более светлые и тёмные оттенки тех же цветов. Шрифты: Lora для заголовков и
Manrope для текста (прежний Cabin не содержит кириллицы, поэтому русский текст раньше показывался шрифтом браузера по умолчанию).

## Как вернуться к прежнему оформлению

Состояние проекта до редизайна – коммит **`aa8bde7`** (последний коммит перед обновлением оформления, он есть в истории ветки);
редизайн выполнен отдельными коммитами после него. Удобное имя для него создаётся одной командой:
`git tag design-v1-old aa8bde7`. Ниже везде можно писать либо `design-v1-old` (после этой команды), либо `aa8bde7`.

| Что нужно | Команда |
|---|---|
| Посмотреть старый сайт, ничего не меняя | `git checkout aa8bde7`, затем `cd frontend && npm install && npm start`; вернуться: `git checkout claude/trusting-meitner-rrfao0` |
| Откатить только оформление клиента, оставив остальные доработки | `git checkout aa8bde7 -- frontend/src` и коммит |
| Откатить редизайн коммитом (история сохраняется) | `git revert <коммит редизайна клиента>`; список: `git log --oneline aa8bde7..HEAD -- frontend` |
| Отложить новый дизайн в отдельную ветку и работать по-старому | `git branch design-v2` (сохранить новое), затем `git checkout -B main aa8bde7` |

Серверную часть откатывать не нужно: новые поля и таблицы (`room_image`, `room_amenity`, столбцы `area`, `view_type`
таблицы `room`) только добавлены, прежний клиент их не использует и продолжает работать, а добавление номера с одним
файлом (поле `file`) по-прежнему принимается. Если нужно убрать и их, команды в конце
[sql/room-design-upgrade.sql](sql/room-design-upgrade.sql).

## Что добавлено в данные номера

* **Несколько фотографий** – таблица `room_image` (первая фотография – обложка карточки); прежнее фото `room.photo`
  при запуске сервера переносится в неё автоматически, а поле `photo` всегда указывает на обложку.
* **Удобства** – таблица `room_amenity` (коды); администратор отмечает пункты в форме номера, список пунктов – в файле
  `frontend/src/app/shared/utils/amenities.util.ts` (новый пункт добавляется одной строкой).
* **Площадь и вид из окна** – необязательные поля `area`, `view_type`.

Эквивалент для администратора БД: [sql/room-design-upgrade.sql](sql/room-design-upgrade.sql).

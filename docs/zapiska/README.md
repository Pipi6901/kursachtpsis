# Пояснительная записка к курсовому проекту

Здесь лежат исходники записки и диаграмм. Готовые файлы Word — в `out/` (по процентовкам, нарастающим итогом).

| Каталог | Что внутри |
|---|---|
| `out/` | готовые `.docx` (процентовка 1, 2, 3) |
| `img/` | диаграммы PNG (4×) и SVG: BPMN AS-IS/TO-BE, конвейер ИИ, варианты использования, контекстная, ER, кривые адстока и насыщения |
| `src/diagrams/` | генератор диаграмм (SVG в headless-Chromium, подписи не рвутся, соединения ортогональные) |
| `src/docx_engine.py`, `src/build.py` | сборка `.docx` на базе стилей образца: поля, шрифты, заголовки, таблицы, формулы (OMML), оглавление, подвал |
| `src/content_p*.py`, `src/sec_*.py` | текст записки |
| `src/template/` | стили, нумерация и подвал образца оформления (без содержимого) |

Сборка (нужны LibreOffice и Poppler для проверки вёрстки и расстановки страниц оглавления):

```bash
cd docs/zapiska/src
python3 build.py 1          # процентовка 1 → ../out/*.docx
node diagrams/render.js     # пересобрать все диаграммы (нужен playwright-core и chromium)
```

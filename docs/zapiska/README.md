## Сборка

Нужны Python 3 с Pillow, LibreOffice и Poppler (вёрстка пробной сборки определяет страницы заголовков для оглавления и места переноса таблиц), для диаграмм и снимков – Node.js, `playwright-core` и Chromium.

```bash
cd docs/zapiska/src
node diagrams/render.js      # пересобрать все диаграммы
python3 optimize_png.py      # сжать рисунки палитрой (иначе .docx получается слишком большим)
python3 build.py 3           # процентовка 3 → ../out/ПЗ_процентовка_3.docx (так же 1 и 2)
```

`build.py` собирает документ несколько раз, пока не установятся номера страниц в оглавлении и места переноса таблиц; PDF рядом с `.docx` нужен только для просмотра и не хранится в репозитории.

## Что проверить в Word после открытия

* оглавление – выделить его и нажать **F9** (обновить поле целиком), номера страниц в Word могут слегка отличаться от пробной вёрстки LibreOffice;
* места переноса таблиц («Продолжение таблицы N.M»), формулы и подписи рисунков;
* отчёт «Антиплагиат» вставить в приложение А (место отмечено жёлтой строкой);
* страницы задания в начале записки заменить подписанным сканом;
* число страниц в реферате и ведомости – после окончательной правки (в записке подставлено по пробной вёрстке).
